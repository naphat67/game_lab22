# Game22 · Your First 2D Game

แบบฝึกหัดที่ 2 ภารกิจ 2 สร้างด้วย Godot 4.7 ตามบทเรียน **Your First 2D Game / Dodge the Creeps!**

- บังคับ Player ด้วยปุ่มลูกศรหรือ WASD
- Mob เกิดจากขอบฉากและวิ่งเข้าหาผู้เล่น
- คะแนนนับเวลาที่เอาตัวรอดได้ ชน Mob แล้วจบเกมและเริ่มใหม่ได้
- ฉากแนวตั้ง 480 × 720 พร้อมภาพ Player และ Mob ที่ปรับแต่งแล้ว
